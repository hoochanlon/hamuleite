# 《Writing Science》提炼、分析与作者核心思想

> **书名**：Writing Science
> 
> **作者**：Joshua Schimel
> 
> **本稿依据**：用户提供的中文译本 PDF
> 
> **整理重点**：全书主旨、方法框架、章节逻辑、实践建议与作者的核心思想

## 一、先给结论

《Writing Science》并不是一本教人“把英文句子写得漂亮”的语言书，而是一套关于**如何让科学知识被理解、记住并产生影响**的写作方法论。作者 Joshua Schimel 的基本判断是：科学写作的任务不只是报告数据，而是把数据组织成一个读者能够跟随的、具有问题意识和因果方向的故事。

全书可以压缩为四句话：

1. **科学家也是专业作家。** 研究成果的影响力不仅取决于研究本身，也取决于别人能否理解、记住并使用它。
2. **科学论文可以用故事结构来组织。** 这里的“故事”不是虚构，而是围绕一个问题展开：研究对象是什么，困难或未知是什么，研究做了什么，最后解决了什么。
3. **数据不是故事的主角。** 数据是证据和行动材料；真正的主角是科学问题、核心假设以及研究对知识的推进。
4. **清晰写作不是清晰思考之后的机械输出，而是产生清晰思考的过程。** 写作、编辑和重写会迫使作者发现逻辑漏洞，明确真正的贡献。

作者最终反对的是“发表数量中心”的学术观。他认为，**发表只是生存，产生可被同行理解、引用和进一步使用的贡献，才是成功**。

## 二、全书的总框架

书中二十一章大致可以分成五个层次。它们不是互相割裂的技巧，而是从“为什么写”逐步推进到“写什么”“怎么组织”“怎么表达”以及“如何产生影响”。

| 层次 | 主要问题 | 核心内容 |
|---|---|---|
| 1. 写作观 | 为什么科学家必须重视写作？ | 写作决定研究能否传播、被理解和产生影响 |
| 2. 故事观 | 科学写作到底在讲什么？ | 从数据中找到故事，以问题和知识推进为主线 |
| 3. 结构观 | 如何组织论文或提案？ | OCAR、ABDCE、LD/LDR 等结构；IMRaD 是外在形式，故事逻辑是内在原则 |
| 4. 语言观 | 如何让读者顺畅理解？ | 清晰的段落、强动词、连贯的信息流、准确而有力度的句子 |
| 5. 传播观 | 如何让文章产生最大影响？ | 针对受众调整结构，在专业读者、全球读者和公众之间切换表达方式 |

作者特别强调，写作原则和写作规则不同。规则可以被灵活调整，原则则不能被轻易破坏。例如，论文通常采用 IMRaD 结构，但 IMRaD 只是常见的外部格式；无论格式如何变化，文章都必须完成“提出问题—展开研究—解决问题”的内在任务。

## 三、第一条主线：科学写作就是讲故事

### 1. “故事”在科学写作中的含义

作者所说的故事，不是加入戏剧化修辞，也不是把论文写成小说，而是建立一条**读者可以追踪的知识路径**。这条路径需要回答：

- 我们正在讨论什么对象或大问题？
- 这个对象存在什么重要的未知、矛盾或困难？
- 研究者采取了什么行动来解决它？
- 这些行动产生了什么结果？
- 结果改变了我们对原问题的什么理解？

因此，科学故事的“角色”通常是研究对象、科学问题、假设或知识体系；“冲突”通常是未知、矛盾、异常结果或理论上的空缺；“行动”是实验、观测、建模、比较和分析；“结局”是结果及其意义。

### 2. 从下往上发现故事，从上往下讲故事

这是全书最有实践价值的工作流程之一。

**从下往上发现故事**，指的是从数据、异常值和具体结果出发，充分探索它们可能意味着什么。作者提醒研究者不要过早把数据塞进一个先入为主的故事。尤其要关注那些“不显著但不寻常”的结果、离群值和无法解释的矛盾，因为真正有新意的发现可能藏在平均趋势之外。

**从上往下讲故事**，指的是完成研究解释后，不要按照自己做实验的时间顺序来写，而要按照读者理解问题的顺序来组织论文。研究过程可能是曲折的，但论文应当展示最清楚、最有说服力的知识路径。

这意味着：**研究的发现顺序，不等于论文的叙述顺序**。

### 3. 数据不是故事本身

作者反复区分“数据”和“故事”。数据只能显示观察结果，故事则说明这些结果为什么重要、它们如何互相联系、它们改变了什么认识。数据是证据，不是目的；图表是材料，不是论点。

一篇论文如果只是依次罗列“我们测了什么、发现什么、又测了什么”，读者可能看到了大量事实，却无法回答“所以呢”。高质量写作必须把数据放进一个更大的知识问题中，并明确告诉读者每个结果承担什么功能。

## 四、第二条主线：用 OCAR 组织科学故事

作者最核心的结构工具是 **OCAR**：

- **O — Opening，开篇**：建立背景，介绍故事对象，说明读者为什么应该关心。
- **C — Challenge，挑战**：提出未知、矛盾、困难或待解决的问题。
- **A — Action，行动**：说明研究做了什么，以及这些行动如何回应挑战。
- **R — Resolution，解决**：给出关键结果、结论及其意义，回到开篇的问题并完成闭环。

| OCAR要素 | 科学写作中的对应问题 | 常见位置 |
|---|---|---|
| Opening | 研究对象和大背景是什么？ | 标题、摘要、引言开头 |
| Challenge | 当前知识缺口或核心问题是什么？ | 引言后半段、研究目标或假设 |
| Action | 采用什么方法和分析来应对问题？ | 方法、结果及其过渡部分 |
| Resolution | 得到了什么结论，改变了什么理解？ | 讨论、结论、摘要末尾 |

### 1. 开篇：不要从“我做了什么”开始

有效的开篇应当迅速建立研究的方向。它通常先介绍一个具有普遍意义的对象或问题，再逐步收窄到本文具体研究。好的开篇让读者知道：这篇文章大致要解决什么问题，以及后文可能向哪里发展。

开篇常见的失败方式有两种：

- **误导方向**：开头强调了一个主题，后文却转向另一个主题，导致读者形成错误预期。
- **不提供方向**：开头充满方法、细节、缩写和局部事实，却没有告诉读者文章为何重要。

作者不是要求每篇文章都用宏大的背景开场，而是要求开篇承担“定位”功能。它可以是一句话，也可以是一整段；关键不在长度，而在于能否让读者建立正确的阅读期待。

### 2. 挑战：把研究问题写成真正可检验的命题

挑战不是泛泛地说“这个问题很重要”，而是要明确指出：**已知与未知之间的具体张力是什么**。优秀的问题通常具有方向性和可检验性，例如某个因素是否真正控制某一过程，某个理论是否能够解释一个异常现象，或者两个看似矛盾的观察能否由同一机制统一解释。

作者特别反对模糊、无风险的陈述。诸如“某因素可能影响某过程”通常既不令人兴奋，也不容易检验。更有力的写法应使用具体动词和明确关系，提出一个可能被证明错误的判断。

科学写作中的“大胆”不等于夸张。作者要求研究者在表达上有明确立场，在科学上诚实承认不确定性。一个有意义的假设必须允许读者理解它的预测，也允许研究者检验它是否成立。

### 3. 行动：方法不是清单，而是解决挑战的行动链

方法部分不能只是仪器、样本、步骤和统计方法的堆积。读者需要理解每一项行动为什么必要，以及它如何服务于核心挑战。结果部分也不应只是按实验顺序排列图表，而应让每个结果推动故事向解决方向前进。

作者不要求所有论文都具有戏剧性，但要求研究行动具有逻辑功能。每个实验或分析最好都能回答以下问题：它是在排除什么可能性？检验什么假设？连接哪两个证据？为最终结论提供什么支持？

### 4. 解决：结论必须回到开篇并完成闭环

结论不是“把结果再说一遍”，也不是用“还需要更多研究”主动削弱自己的贡献。有效的解决部分应当完成三件事：

1. 明确指出最重要的发现；
2. 说明发现对原问题和更大领域意味着什么；
3. 回到文章开头提出的背景或挑战，展示知识如何发生了变化。

作者把好的故事比作“螺旋”：结尾回到开头，但回到的是一个已经被研究改变过的起点。科学论文也应如此：结论不是简单重复背景，而是让读者看到我们现在比开头知道得更多。

## 五、第三条主线：让故事变得“黏”——SUCCES

作者借用“黏性信息”的概念，提出让科学信息更容易被理解和记住的 **SUCCES** 原则。不同版本的表述略有侧重，但核心可以概括为以下六点：

| 要素 | 含义 | 在科学写作中的做法 |
|---|---|---|
| **Simple 简单** | 找到并突出核心信息 | 用一句话说清论文真正贡献，删除不服务于主线的内容 |
| **Unexpected 意外** | 提供与读者预期不同但有意义的信息 | 突出反常结果、理论矛盾和真正的新发现 |
| **Concrete 具体** | 让抽象概念落到可想象的对象和关系上 | 用具体对象、过程、数量和动作替代空泛概念 |
| **Credible 可信** | 让读者相信论断有证据支撑 | 明确证据链、限定结论范围、诚实呈现不确定性 |
| **Emotional 有关切** | 让读者感到问题值得关注 | 说明研究对知识、实践或更大问题的意义 |
| **Stories 故事化** | 将事实组织成可追踪的变化过程 | 用问题、行动、结果和意义连接证据 |

“简单”不是把复杂问题粗暴简化，而是识别复杂系统中最值得读者记住的核心。“具体”也不是堆叠技术细节，而是让抽象名词转化为清楚的对象、动作和关系。“意外”不是制造噱头，而是指出真正改变预期的发现。

这套原则的共同目标是降低读者的认知负担。读者不是因为信息越多而越容易理解，而是因为信息之间的关系越清楚而越容易理解。

## 六、从整篇文章到句子：内部结构与语言

### 1. 段落是微型故事

作者把段落看作文章的基本叙事单元。一个有效段落通常包含：

- 一个清晰的主题句，告诉读者本段要处理什么；
- 若干按照逻辑顺序展开的证据、解释或例子；
- 一个把本段结论连接到下一步的收束或过渡。

段落不应同时承担多个没有关系的任务。读者需要能够回答：“这一段的中心命题是什么？”如果答案只能通过读完整段后猜测，主题句往往不够明确。

作者还强调段落内部的“沙漏”结构：先从较大的问题进入，再收窄到具体证据，最后重新打开到更大的意义。这样的结构能把细节与主线连接起来，避免段落变成孤立的信息盒子。

### 2. 句子要让动作显现出来

书中反复倡导使用强动词、主动语态和具体主语。作者尤其批评两类表达：

- **模糊动词**：如“影响、涉及、进行、导致、被控制”等被过度使用的动词，它们常常隐藏真正的关系。
- **名词化**：把动作藏进名词中，再用一个空泛动词支撑句子，例如把“we investigated”写成“we conducted an investigation”。

强动词的作用不只是让句子更短，而是让科学关系更明确。比较而言，“研究了某因素对生长的影响”比“进行了关于某因素对生长影响的研究”更直接；“某因素限制了生长”比“生长受到某因素的限制”更有行动方向。

主动语态并不是绝对规则。作者的原则是：当行动者重要时，明确写出行动者；当过程本身比行动者重要时，可以使用被动语态。关键是不要让句法掩盖逻辑。

### 3. Flow：让读者知道下一句话为什么出现

连贯性不是靠连接词堆出来的，而是靠信息位置和概念重复建立的。作者关注两个基本问题：

- 每句话的开头是否承接了上一句话已经建立的内容？
- 每句话的结尾是否提出了下一句可以继续发展的新信息？

如果句子开头不断引入新概念，读者就会感觉文章在跳跃；如果关键新信息总被放在句子中间，读者也难以抓住重点。好的信息流会让读者产生“这句话自然引出了下一句话”的感觉。

### 4. 压缩不是删字，而是保留功能

作者的压缩原则不是追求最短，而是删除不承担功能的内容。修改时应先问：这句话在故事中做什么？它是在建立背景、提出挑战、提供证据、解释机制还是说明意义？如果无法回答，它可能不需要存在。

压缩还包括：减少重复的背景、合并功能相同的句子、删除空泛修饰语、把多个弱动词改成一个强动词，以及把分散的核心结论集中到读者最容易注意的位置。

## 七、作者对不同写作场景的建议

### 1. 论文与提案

专业论文通常可以采用较完整的 OCAR 结构，让读者逐步进入问题，再沿着研究行动走向结论。研究提案面对的读者往往时间更少，因此需要更早、更明确地呈现挑战、创新点和预期解决方案。对提案而言，读者必须尽快知道：问题是什么、为什么重要、为什么现有方法不够、你准备怎样推进。

### 2. 讨论部分

讨论部分不应成为结果的重复清单。它应当重新组织结果，说明结果如何回答挑战，并进一步解释机制、意义和限制。讨论可以采用 OCAR，也可以用 LDR，即先给出核心结论，再展开证据和含义。所谓“正确结构”不是固定模板，而是由受众的耐心、文章的目的和信息的性质决定。

### 3. 全球科学写作

面向国际读者时，作者应尽量减少只在本地学术文化中有效的隐含前提、习惯性表达和不必要的复杂句法。全球科学交流的目标不是展示语言能力，而是让不同背景的读者都能准确理解研究问题、证据和结论。

### 4. 面向公众写作

专业写作和公众写作的原则相同：都需要清晰的故事、具体的对象和可信的证据。但公众读者通常不具备专业背景，因此必须减少术语，解释必要概念，并把研究意义放进读者熟悉的问题中。公众写作不是降低科学标准，而是改变解释路径。

## 八、作者的核心思想

如果要用一句话概括作者的核心思想，可以表述为：

> **科学写作的本质，是把数据转化为一个清晰、可信且对读者有意义的知识故事；写作不是研究之后的包装，而是发现问题、检验逻辑和产生科学影响的一部分。**

这一思想包含五个层次。

### 第一，科学知识必须通过传播才能成为影响

研究成果如果无法被同行理解，就难以被引用、验证、继承和发展。写作不是科研之外的行政负担，而是科研价值实现的路径。作者因此把“有效写作”与“学术成功”直接联系起来。

### 第二，写作会反过来塑造思考

作者反对“先把思想想清楚，再把它写清楚”的简单顺序。写作过程会暴露概念混乱、证据不足、逻辑跳跃和结论过度。重写不是文字美容，而是思想校准。

### 第三，科学严谨与故事性并不冲突

科学故事不是虚构，也不是煽情。它只是把科学事实按照问题、证据和知识变化的逻辑排列起来。故事结构提高的是可理解性，不是降低证据标准。

### 第四，最重要的写作不是增加信息，而是做出取舍

数据可以很多，论文的核心贡献通常只能有一个或少数几个。作者要求研究者先充分探索数据，再用类似奥卡姆剃刀的方式削减，找到最值得讲述的核心。好的写作既需要开放探索，也需要克制取舍。

### 第五，质量最终胜过数量

“发表或灭亡”只能说明学术生存压力，不能定义真正的成功。真正的同行会识别哪些论文改变了他们的思考。结构清晰、观点有力、结论有影响的少数论文，比大量无人阅读和引用的论文更能推动事业与学科发展。

## 九、对这本书的分析与评价

### 1. 它最有价值的地方：把宏观结构和微观语言连接起来

许多写作书只讲句子，或者只讲论文结构。《Writing Science》把两者连接起来：一篇文章的清晰度来自宏观故事，也来自每个段落和句子对故事的持续推动。OCAR 解决“整篇文章往哪里走”，SUCCES 解决“读者为什么愿意跟随”，强动词和信息流解决“读者能否顺利走下去”。

### 2. 它对“科技写作”的重新定义

传统观念常把科技写作理解为客观、克制、无个性地排列事实。作者则指出，所谓客观并不等于没有结构，克制也不等于模糊。科学文章同样需要选择重点、安排顺序、制造预期和解释意义。真正的客观性不是隐藏作者的判断，而是清楚区分数据、推论和不确定性。

### 3. 它最值得警惕的边界

故事结构是一种组织工具，不是证明工具。好的叙事不能修复有缺陷的研究设计，也不能用语言掩盖证据不足。作者本人也承认，写作技巧不能把“煤炭”变成“钻石”；它能做的是从不完美的数据中识别有价值的核心，并诚实地突出其边界。

此外，OCAR 不应被机械套用。不同学科、不同文体、不同读者需要不同的信息顺序。作者强调“原则优先于规则”，因此最合理的使用方式不是把每篇论文硬改成同一个模板，而是检查文章是否完成了提出问题、推进证据和解决问题的功能。

## 十、可直接使用的写作检查表

### 动笔前

- 我这篇文章真正要回答的一个核心问题是什么？
- 读者为什么应该关心这个问题？
- 数据中最意外、最有解释力或最能改变预期的发现是什么？
- 如果只能让读者记住一句话，这句话是什么？

### 写初稿时

- 开头是否明确建立了研究对象和重要背景？
- 挑战是否具体、可检验，并且真正构成知识缺口？
- 每个实验或分析是否都在回应一个明确的挑战？
- 结果是否按照知识逻辑，而不是实验发生顺序排列？
- 结论是否回答了开头提出的问题？

### 编辑时

- 每个段落是否有明确主题句？
- 每句话的开头是否承接了前文？
- 是否存在模糊动词、过多名词化或不必要的被动语态？
- 是否把最重要的信息放在句子和段落的显眼位置？
- 是否有重复背景、空泛修饰语和不服务于主线的细节？
- 是否明确区分了数据、解释、推测和局限？

### 完稿后

- 一个不了解本领域的聪明读者能否复述我的故事？
- 一个本领域同行能否准确指出我的创新和边界？
- 文章结尾是否让读者理解“这项研究改变了什么”？
- 文章是否值得被引用，而不仅仅是满足发表要求？

## 十一、最终总结

《Writing Science》的真正贡献，不是提供一套可以机械套用的英文句式，而是改变科学家看待写作的方式。写论文不是把已经完成的研究翻译成文字，而是重新组织研究，使它成为一条可理解、可检验、可记忆和可传播的知识路径。

作者希望科学家成为“科学家—作家”：既能做可靠的研究，也能说明研究为什么重要；既能尊重数据，也能从数据中提炼出问题和意义；既能承认不确定性，也敢于提出清晰而有挑战性的判断。

因此，本书最核心的行动建议可以浓缩为：

> **先深入倾听数据，找到真正的故事；再围绕读者组织故事；最后通过不断写作、编辑和重写，让思考变得清晰，让研究真正产生影响。**
