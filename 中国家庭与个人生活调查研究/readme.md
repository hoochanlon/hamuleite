## 六、建议的阅读顺序

第一步，先读 **CFPS、CGSS、CSS** 的项目介绍，理解调查对象、抽样范围、追踪频率、问卷层次和数据权限。第二步，按研究问题选主数据：家庭关系和生活变迁选CFPS；资产、负债和消费选CHFS；长期收入分配和消费选CHIP；教育和家庭背景选CEPS；劳动和职业流动选CLDS；中老年健康和家庭支持选CHARLS。第三步，再用CPLS、大学生婚育观调查、妇女社会地位调查和性生活调查补充主数据不擅长的专题。第四步，回到问卷、抽样设计、变量说明和代码本，尤其不要把“研究中国青年”误读成“样本代表所有中国青年”。

## 七、核验时要注意的误区

1. **报告不等于调查。**《中国家庭金融研究（2020）》是基于2019年CHFS数据的研究报告，不是一次新的调查。
2. **数据库不等于调查。**CSDA、CNSDA和北大开放研究数据平台是数据归档和共享基础设施，不是新的被访者项目。
3. **网民不等于全体青年。**复旦青年网民报告的对象是特定平台的活跃用户，不能直接外推到全部青年。
4. **在线调查不自动具有全国代表性。**CPLS的核验论文说明了调查设计和变量，但现有材料没有把它表述为全国概率抽样代表性调查。
5. **有数据入口不等于全部数据可直接下载。**CFPS、CHARLS、CHFS、CNSDA收录项目普遍存在注册、审核、研究计划、协议或分级权限。
6. **机构相近不代表项目相同。**北大可确认CFPS、CPLS参与机构和CSDA；人大可确认CGSS、CEPS、全国性生活调查等；社科院可确认CSS、大学生追踪、社会心态调查等，应按正式项目名区分。

## 阅读这些论文时的示范方法

以“家庭与个人生活”为例，可以先提出一个可检验的问题，例如“家庭经济压力是否影响心理健康”。随后要确认数据项目是否包含家庭收入、债务、健康和心理变量，再查看论文使用了哪几个波次、对象年龄和最终分析样本。接下来需要区分横截面分析和纵向分析：单一波次只能描述同一时间点的关联，多波次面板更适合观察个体内变化，但仍然不自动等于因果关系。最后要核对缺失值处理、权重、固定效应、自然实验或差分中的差分等模型设定。

同样的问题在不同项目中的可回答程度不同。CFPS和Understanding Society适合家庭—个人—社区或家庭—个人的长期变化；CHFS、SCF、WAS和日本家计调查更适合资产、储蓄、消费与负债；CHARLS、HRS、ELSA和TLSA更适合中老年健康、退休和家庭支持；CPLS、NSFG、JNFS和PSFD更接近婚恋、性、生育和亲密关系，但必须特别核对样本代表性和敏感问题的测量方式。

## 十、六大板块的最低完整覆盖结论
