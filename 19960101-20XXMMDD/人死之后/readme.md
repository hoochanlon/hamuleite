丧葬补助金+抚恤金（俗称丧葬费）高低的影响因素（湖南职工养老政策） 
 
职工养老待遇分两块：丧葬补助金 + 抚恤金，两者合起来是遗属待遇；另外养老保险个人账户余额可以单独继承，不算丧葬费。
 
1、本省上年度城镇居民月人均可支配收入（核心基数） 
 
- 丧葬补助金 = 这个基数 ×2个月，全省统一。
- 抚恤金也是拿这个基数来乘月数。
 
每年会更新，年份不一样，同样条件，拿到手钱不一样。
 
2、养老保险缴费总年限（含视同缴费年限） 
 
在职没退休就去世
 
- 缴费＜5年：抚恤金3个月；总额不能超过个人缴费部分
- 5‑10年：6个月
- 10‑15年：9个月
- ＞15年，每多交1年+1个月，封顶24个月（缴费满30年）
 
交的越久，抚恤金越高。
 
已经退休后去世
 
1. 先按上面缴费年限算出抚恤金最高月数；
2. 每领1年养老金，抚恤金扣减1个月，最低保留9个月。
 
例子：缴费28年，领了12年养老金，就要扣12个月，但不会低于9个月。
 
3、参保类型差别，差距非常大
 
1. 企业职工养老保险（含灵活就业）：既有丧葬补助金，又有抚恤金，总额几万到十几万 。
2. 城乡居民养老保险：大部分区县只有一笔很低的丧葬补助，没有抚恤金；郴州各个县标准不一样，几千元以内，困难群体统一1200元 。
3. 机关事业单位：单独一套算法，抚恤金会比企业职工高很多。
 
4、死亡原因
 
- 因病、意外（非工伤）：走养老保险遗属待遇。
- 工伤死亡：走工伤保险工亡赔偿，不走养老保险丧葬费，两套不能重复领。
 
❗不影响丧葬费高低的几件事（很多人误会）
 
1. 火化还是土葬：湖南企业职工养老不看是否火化，不扣钱 。
2. 死者工资、退休金高低：不直接决定丧葬费多少，不是退休金越高丧葬费就越高。
3. 家属有几个人：待遇总额固定，只是家里人内部分配，总数不变。
4. 年龄大小：不直接影响，间接通过缴费年限、领养老金年限体现。
 
简单举郴州例子（职工养老）
 
基数用湖南2025年月均可支配：4447元 
 
1. 缴费30年，刚退休就去世：
丧葬：4447×2=8894；抚恤金：4447×24=106728；合计约11.5万。
2. 缴费30年，已经领了15年退休金去世：
抚恤金最低锁死9个月，总待遇≈(2+9)×4447≈4.9万。
 
缴费时间越长、领养老金的时间越短，拿的遗属待遇就越高。
