## 无暇赴死

### 核心计发基数（全省统一）

- **丧葬补助金** = 本省上一年度城镇居民月人均可支配收入 × **2**
- **抚恤金** = 同一基数 × 对应月数

2025年湖南城镇居民人均可支配收入为**53369元/年**（2026年1月官方公布），月均约**4447.42元**。因此2026年死亡的计发基数按此执行：

- 丧葬补助金固定约 **8895元**
- 抚恤金最高约 **10.67万元**（24个月），最低约 **4万元**（9个月）

### 1. 没有正式工作、未参加企业职工养老保险的人

- 如果**从未参加**企业职工基本养老保险（只参加城乡居民养老保险，或者完全没参保）：
  - **没有**企业职工那套“丧葬补助金 + 抚恤金”（几万到十几万）。
  - 城乡居民养老保险：个人账户余额可以依法继承；丧葬补助金方面，湖南大部分县市区标准很低或尚未统一建立，已建立的通常只有几千元（例如按当地基础养老金×12个月，约2000多元；郴州特殊困难群体统一1200元）。
  - 完全没参保：从养老保险系统几乎拿不到钱（只有可能其他社会救助，但不是这笔遗属待遇）。

所以这类人去世后，家属从养老保险拿到的钱**确实少得多，甚至接近没有**。

### 2. 个体户 / 灵活就业人员

- **关键看他有没有以灵活就业身份参加企业职工养老保险**。
  - 如果参加了（湖南已取消户籍限制，鼓励个体户、新就业形态人员以个人身份参保），**待遇规则完全和企业职工一样**：丧葬补助金 + 按缴费年限计算的抚恤金。
  - 缴费年限长的，也能拿到接近或达到最高档（几万到十几万）。
  - 如果只交了城乡居民养老保险，或者断缴、缴费很短，那就和上面“没正式工作”的情况类似，金额低很多。

很多人误以为“个体户就一定没这份钱”，其实只要他按灵活就业交了企业职工养老，就有。

### 3. 当下的年轻人

- 即使参加了企业职工养老保险，**缴费年限短是硬伤**：
  - 缴费＜5年：抚恤金只有3个月，而且总额不能超过个人缴费部分（实际到手往往很少）。
  - 5–10年：6个月。
  - 10–15年：9个月。
  - 要拿到比较高的金额，通常需要缴费15年以上，最高要接近30年。
- 年轻人如果工作不稳定、断缴多、或者从事零工/灵活就业却没主动参保，缴费年限普遍较短，因此去世后家属能领到的遗属待遇**明显低于**缴费二三十年的中年/退休人员。
- 再加上很多人只交最低基数，个人账户积累也少，整体差距会更大。


### 职业对比


| 类型              | 待遇内容                                                     | 大致金额       |
| ----------------- | ------------------------------------------------------------ | -------------- |
| 企业职工/灵活就业 | 丧葬补助金 + 抚恤金                                          | 几万到十一二万 |
| 城乡居民养老保险  | 多数区县仅有较低丧葬补助（或无），无抚恤金；郴州特殊困难群体统一1200元 | 通常几千元以内 |
| 机关事业单位      | 单独政策，抚恤金按本人生前工资/退休费月数计算，普遍高于企业职工 | 显著更高       |

### 简单对比（按2026年湖南基数约4447元/月粗算）

| 情况                        | 大概能领多少（丧葬+抚恤）             | 说明       |
| --------------------------- | ------------------------------------- | ---------- |
| 缴费30年企业职工（刚退休）  | 约11.5万                              | 最高档     |
| 缴费15年企业职工（在职）    | 约4–5万                               | 中等       |
| 缴费5–10年企业职工/灵活就业 | 约2.7–3.5万                           | 已经少不少 |
| 缴费＜5年                   | 通常几千到1万多（受个人缴费上限限制） | 很少       |
| 只参加城乡居民养老          | 个人账户余额 + 可能的几千元丧葬补助   | 少得多     |
| 完全没参保                  | 几乎没有（从养老系统）                | 基本没有   |

**总结**：
 没有稳定工作和长期企业职工养老保险缴费记录的人（包括很多个体户、灵活就业者、年轻人），去世后家属从养老保险拿到的钱，确实**比缴费年限长的正式职工少得多，甚至接近没有**。核心决定因素不是“有没有工作”这个标签，而是**有没有参加企业职工养老保险 + 累计缴费了多少年**。
