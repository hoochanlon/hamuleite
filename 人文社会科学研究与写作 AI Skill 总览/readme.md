### 二、推荐的最小工作流

对于大多数人文社会科学研究任务，可以采用以下五步流程：

1. 使用 `humanities-thesis-skill` 或 `ARS-Codex` 明确研究问题，避免一开始就要求工具生成整篇论文。
2. 使用 Zotero 建立统一文献库，并用 Better BibTeX 管理引用键。所有进入正文的文献都应核验作者、题名、年份、版本和页码。
3. 使用 ChatPaper、STORM、GPT Researcher 或 PaperQA2 进行初步检索、摘要和比较，但应将 AI 输出视为研究线索，而不是最终证据。
4. 对访谈、田野笔记和文本材料使用 QualCoder 或 Taguette 建立可追溯的编码记录，并保留编码规则与修改过程。
5. 完成初稿后，先用 `humanities-thesis-skill` 检查“问题—理论—材料—结论”的对应关系，再用 `social-science-paper-writing-skill` 检查证据缺口、引用风险和因果推断是否过度。

### 三、文献引用与学术诚信底线

- 建立“论断—原文证据—页码或位置—文献条目”的对应关系。没有原文和明确位置时，不应使用“研究表明”“作者指出”等强断言。
- AI 生成的 DOI、页码、引语、统计数字、法律条文和历史细节，均应默认视为未核验信息，并回到原文或官方数据源进行确认。
- 区分“仅有元数据”“仅阅读摘要”“已阅读全文”“已定位页码”和“研究者已复核”等不同证据等级，不要把搜索摘要或模型摘要当作全文证据。
- 保留检索式、筛选标准、下载版本、AI 提示词、修改记录、数据处理过程和人工核验记录，以便复核研究过程。
- 对访谈材料、未公开档案、个人信息和受版权保护的材料进行必要脱敏，并遵守学校、期刊、资助机构及数据提供方关于 AI 使用的规定。
- AI 可以辅助检索、整理、改写和检查，但不能替代研究者的原创判断、证据核验、署名责任和学术诚信责任。
