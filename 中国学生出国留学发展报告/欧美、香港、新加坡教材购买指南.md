# 欧美、香港、新加坡教材购买指南：去哪儿买，怎么买最省钱

> [!important]
> 人工智能披露：由 元宝 生成


> 核心原则：**教材这件事，"买"永远是最贵的选项。**
> 
> 正确的决策顺序是：图书馆借 → 免费开源教材 → 二手 → 租赁 / 电子版 → 国际版 → 最后才是新书。


## 一、美国 / 加拿大

| 类型 | 网站 | 关键点 |
|---|---|---|
| 综合新书 | Amazon | 品类最全，Prime 快，但很少是最低价 |
| 二手（首选） | **AbeBooks**（亚马逊旗下）、**ThriftBooks**、Better World Books、Alibris | AbeBooks 是找**旧版 / 绝版**最全的地方，页面上常有 International（国际影印）版；ThriftBooks 满 $10 包邮 |
| 租赁 | **Chegg**、eCampus、Textbooks.com、ValoreBooks、Knetbooks | Chegg 实体书租赁双向包邮，21 天内可退；eCampus 有积分返利 |
| 电子版 | **VitalSource**、RedShelf、Kindle | VitalSource 常比纸质便宜 40–60%，不用寄回；很多学校的 "inclusive access / first-day access" 就是通过它下发，机构价远低于零售 |

**租赁别只看标价**：要算退回运费、逾期费和破损费。Chegg 免双向运费这点很值，Amazon 退回运费要 $15–20。

## 二、英国 / 欧洲

| 网站 | 说明 |
|---|---|
| **Blackwell's**（blackwells.co.uk） | 英国最大学术书店，1800 万+ 书目，**全球免运费到 110 多个国家**（含中国内地、香港、新加坡），学术书折扣给得足，学生有折扣期 |
| Wordery | 2025 年 11 月重新上线，**目前只发英国境内**；国际订单官网自己都推荐去 Blackwell's |
| Waterstones / Foyles / Hive | 英国本土连锁，Hive 下单会分润给独立书店 |
| AbeBooks、World of Books、Oxfam 线上店、eBay | 二手主力 |
| Amazon.de / .fr / .nl、Thalia（德）、Fnac（法）、Bol.com（荷）、Adlibris（北欧） | 欧陆按国别本地化买，运费和税更省 |

> ⚠️ **Book Depository 已于 2023 年 4 月 26 日正式关闭**（被亚马逊砍掉），很多老攻略里还在推它，别白跑。

## 三、香港

### 新书

- **商务印书馆**（22 家分店，报 ISBN 就能查，缺货可预订）、**三联书店**、**中华书局**、香港大众书局
- **Elephants**（elephants.com.hk）—— 2015 年成立的网上书店，专做高中和大学的英文 / 中文教材，覆盖法律、会计、理科等，可配送或自取
- 教图、T.H. Lee、诚品 Eslite

### 二手（省钱主战场）

- **Carousell HK**：最主流，多数教科书 100 港币以内
- **BookDaddy**（bookdaddyhk.com）：专为学生家长做的二手书平台，免费上架，支持用 **ISBN 直接搜版本**
- **Facebook 各校二手书群**（搜"学校名 + 二手書"，如 cityu book trade）、**孔夫子旧书网**（绝版 / 文科书能淘到，偶尔溢价）
- 实体：旺角西洋菜街一带最密集 —— 汉文书店、汉记书局（二手约 6 折）、**柠檬书店**（lemonbookstore.com，4–5 折起，可线上下单门店取）、学生书屋；另有佐敦学友书店、西营盘校友书局、北角精神书局

### 两条本地省钱铁律

1. 香港课本有 **"五年不改版"** 规定，书单若注明"重印"或"重印兼订正"，内容差别极小，**可以直接用旧版**（跟老师确认一下即可）
2. **港硕先别急着买书** —— 授课型硕士多数课程老师直接发 PDF 阅读材料、期刊文章、E-book 章节，先看完 Course Outline 再决定

价格参考：本地教材 HK$100–200，原版英文专业教材（商科 / 工程 / 医学）**HK$300–1000+** 很常见。另外图书馆 + **JULAC 跨校借书证**一定要用起来。

## 四、新加坡

### 新书

- **Popular 大众书局**（popular.com.sg）：全岛 27+ 门店，教科书、练习册最齐；**学生会员卡 S$8/年，教科书 5% 折扣**
- **Times**（timesbookstores.com.sg / Goguru）、**Kinokuniya 纪伊国屋**（英文书最全）、MPH
- **OpenSchoolbag**（openschoolbag.com.sg）：本地教材专营
- 校园书店：NUS Co-op、BookHaven（NUS UTown）、Booklink（SMU / NTU / RP / JCU）

### 二手

- **Carousell**：新加坡二手教材最大的池子，中学书 S$5–15、大学书 S$10–40，可按学科 / 年级筛选，注意看卖家评分
- **Thryft**：NUS 学生创办的二手书平台，可拿旧书换积分，S$15 以上免运费
- Shopee（有 Shopee Guarantee 保障）、Facebook Marketplace（家长清仓，有时免费送）
- 实体：Bras Basah Complex 一带 —— BooksPlus（S$8–20 中学 / S$12–35 大学，可抵价换书）、Knowledge Book Centre、Basheer Graphic Books

价格参考：一本大学新教材 **S$80–200**，二手通常能省 30–70%。开学前学校常办旧书义卖（中小学 12–1 月、理工和大学 7–8 月），是全年最好的捡漏窗口。

## 五、人还在国内，怎么提前买

- **中国图书进出口集团（中图）**：国内少数有教材进口资质的渠道，旗下有中图教育平台（cnpeducation.com，主要服务国际学校）和海外图书采选系统（cnpbook.com）；在当当、京东、天猫开有"中图上海进口图书旗舰店"等店，有现货也有海外预定（**预定一般 1–3 个月发货**）
- **外图台湾书店**（当当店）：Cambridge International AS / A-Level 这类国际课程教材能买到
- 淘宝 / 闲鱼：影印版、电子版便宜，但版权和印刷质量要自己权衡
- 亚马逊海外购、京东国际

> 如果已经拿到录取，**直接让 Blackwell's 寄到国内反而更简单** —— 全球免运费，价比中图现货常常还低。

## 六、比价工具 & 卖书回血

- **SlugBooks**、**BigWords**、**DirectTextbook**：输入 13 位 ISBN，一次性聚合上百个卖家的新书 / 二手 / 租赁 / 电子价，几分钟就能省 $50–100
- **BookScouter**：专门比"卖书价"，学期末把书卖回去，通常能回收 25–50% 成本


## 七、免费正版教材（很多人不知道）

| 平台 | 适合 |
|---|---|
| **OpenStax**（openstax.org，莱斯大学） | 80 本同行评审教材，覆盖生物 / 化学 / 物理 / 微积分 / 经济 / 心理 / 社会学导论课，**免费 PDF + 低价印刷版** |
| **LibreTexts**（libretexts.org） | STEM 深度最强，3000+ 教材，可导出 PDF |
| **Open Textbook Library**（open.umn.edu） | 明尼苏达大学运营，附教授评审，能提前判断好不好用 |
| **OER Commons / MERLOT / Saylor** | 综合开放教育资源检索 |
| **MIT OpenCourseWare** | 2500+ 门课的讲义、习题集和答案，没教材时能顶上 |
| **Open Library / Internet Archive** | 借旧版扫描本（旧版往往只差习题编号） |
| **DOAB** | 10 万+ 学术专著免费阅读 |

## 八、四个必踩的坑

1. **只认 ISBN**。13 位码对了才能确保版本对，教授指定的版本买错一本就是废纸。
2. **Access code 陷阱**。Pearson MyLab、WileyPLUS、Cengage MindTap 这类作业平台码，二手书不带，得单独买，**有时比书还贵** —— 先问清楚这门课到底用不用。
3. **国际版（International Edition）**：便宜一大截，但纸张装订差、ISBN 不同、部分标注 "Not for sale in the US"，且**课后习题编号可能与美版不一致**。买之前确认老师要求的习题来源。
4. **别在开学前两周下单**。那是全年价格最高、库存最紧的时候；开学一两周后退课的同学集中抛售，价格能再降 20–30%。

## 结语：一套可复制的操作顺序

拿到书单 → 抄下 ISBN → 先查图书馆和 OpenStax → 再上 SlugBooks 比价 → 二手 / 租赁 → 实在没有才买新书。

一门课省几百块，一学期下来就是几千。
