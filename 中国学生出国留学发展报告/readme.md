## A-Level & SAT

国际学校的学生由学校教务部门统一组织集体报名，社会考生则需通过英国文化教育协会的 SRS 报名系统自主报名。总之，除了要有钱，流程也不省心……

|          | A-Level             | SAT            |
| -------- | ------------------- | -------------- |
| 所属体系 | 英国                | 美国           |
| 本质     | 课程体系 + 入学考试 | 标准化能力测试 |
| 备考周期 | 通常 2 年           | 相对较短       |
| 核心用途 | 申请英联邦国家大学  | 申请美国大学   |

- A-Level 全称 General Certificate of Education Advanced Level，是英国的大学入学考试课程，相当于英国的"高考"。
- SAT 全称 Scholastic Assessment Test，俗称"美国高考"，由美国大学理事会（College Board）主办。

国内本科毕业后留学，通常是申请硕士（研究生），主要看这几项：

- **本科成绩（GPA）**：最核心的硬件指标
- **语言成绩**：雅思 / 托福（英国通常要求雅思 6.5–7.0）
- **个人陈述（PS）**：说明你的学术兴趣与申请动机
- **推荐信**：一般需要 2 封学术推荐信
- **其他**：部分专业可能要求 GMAT / GRE、作品集或工作经验

> 本部分由千问生成。

移民不是办完手续就完事，而是一条很长、很贵、随时可能断的路。

**身份是一环扣一环的**
 
学生签证 → 工作签证（要抽签、绑雇主）→ 申请绿卡 → 排期等待（中国人特别多，EB-2类可能要等二十多年）→ 拿到绿卡 → 再等5年才能入籍。中间任何一环断了（失业、抽签没中、撑不到排期），前面都白费。

**这条路普通家庭很难走通**

出国留学一年费用常常超过家庭年收入。钱多半来自父母存款、卖房、借款。真正能走到绿卡的，往往是中产以上、愿意把家底压在一个孩子身上的家庭。普通工薪家庭风险太高、周期太长，很难撑下来。

**拿到绿卡后，很多人故意不入籍**

对中国人来说，入美国籍 = 自动失去中国国籍（中国不承认双重国籍）。入籍后：
* 回中国变成外国人，要签证
* 处理国内房产、账户更麻烦
* 照顾国内父母更不方便

绿卡已经能让你长期合法留在美国。很多人算完账觉得：入籍的好处不够大，但失去中国身份的代价很大，所以选择长期拿着绿卡，保留退路。

**家庭常见做法：一个人入美籍，另一个人和孩子保留中国籍+美国绿卡。两边都留一手**

一句话总结：移民本身已经很难、很贵、很漫长。对中国人来说，入籍又是一次不可逆的“换国籍”，所以很多人宁愿停在绿卡阶段，不关最后那扇可以回头的门。
