首先打开这个欧盟委员会[投诉专题页面](https://competition-policy.ec.europa.eu/state-aid/complaints_en)，下载里面的一个doc文档，然后按照doc文档里面的要求，填写相关信息，doc文档及中英文对照表见附件，举报的公司不在欧盟列表也可以举报，只需要举报对应公司上游在欧盟国家有供应链合作关系的公司就行，电子邮箱里面可以包含相关公司的图片附件及相关文件，编辑好doc文档后把文档用电子邮箱的方式发送到欧盟委员会邮箱，欧洲工会联合会邮箱也可以发送一份，推荐使用Proton邮箱和Gmail邮箱，doc文档里面也可以申明使用匿名的方式投诉，您的投诉结果将在15个工作日内收到投诉结果。

投诉举例

- **996工作制**：强迫员工每天工作超过12小时，违反正常的工作时间规定。
- **过度加班**：员工经常被要求加班，超过了法律规定的每日8小时工作时间。
- **没有五险一金**：公司没有为员工缴纳社保、医疗、养老等法定保险。
- **劳务派遣**：公司通过劳务派遣公司雇佣员工，避免为他们提供正职员工的福利。
- **降薪增工时**：公司在没有明确通知的情况下，强迫员工接受降低薪资和增加工时的安排。
- **巧立名目扣罚**：以各种理由扣除员工工资，或采取其他不正当手段压榨员工。
- **外包问题**：存在大量外包工作，且外包员工的待遇远低于正式员工。
- **虚假承诺和限制自由**：入职时承诺的福利和条件与实际严重不符，且对员工行动进行限制。
- **债务奴役和扣发工资**：通过工资延迟支付和恶意扣罚迫使员工继续工作。
- **恐吓威胁与恶劣环境**：通过恐吓手段威胁员工，工作环境缺乏基本的安全和卫生条件。
- **隐性强迫劳动形式**：利用劳务派遣和外包隐匿真实用工情况，逃避监管。
