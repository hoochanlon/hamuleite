## 序章

### 早熟的宿命感

现代社会的架构里，一个无人脉、无资源、无土地依托，父母能力普通、自身相貌平平的年轻人，想要取得超越父辈的成就，本质上不是一道价值判断题，而是一个大数据问题 —— 概率无限趋近于零。

过去的年轻人囿于信息闭塞，大多是后知后觉。很多人要熬到三十多岁，在反复碰壁后，才慢慢认清自身命运的上限。而现在，互联网、AI、无处不在的现实样本，把这份 “醒悟” 的时间，狠狠向前推了一大截。从前要到三十岁一事无成才明白的事，很多人刚走出校门，就已经看见了。

### 出卖与支配

常说消费拉动经济，表层解释是加快货币流转。但从劳动力再生产的视角看，它还有一重隐秘的作用：抬高底层生存成本，持续消耗普通人的积蓄，制造刚性支出压力，迫使劳动者不断重返生产。这套体系害怕劳动者拥有停下劳动的选择权；源源不断、可供支配的劳动时间，才是它赖以运转的根基。但这只是单一批判视角，不能替代总需求、技术进步等解释，体系内部本身也存在矛盾：过度掏空底层，最终会反噬市场购买力，催生需求萎缩的危机。

学历、技能、外语、口才、心智、外貌，全部都是你这个 “人力工具” 的改装升级件。你打磨它们，是为了提高单位时间的售卖价格；但人的生理、精力有折旧，一定会越用越贬值，市场上还持续不断有更年轻、成本更低、耐受度更强的新人补上。

对普通人来说，首要目标是提升劳动生产率，拉高单位时间收入，把劳动产生的剩余沉淀为生产资料；并且要守住结余，避免房产、车辆、消费主义、彩礼、社交媒体形象展示这类事项持续掏空财富。人与人根本性的区别，不在于劳动生产率的高下，而在于生产资料占有量的悬殊。这是有产者对劳动者的降维打击，也是掌握资产的人，对只能出售自身时间的工具人的降维打击。

综上，钱本质是调配时间资源的工具。这本身就是一种权力。对一个人来说，当积蓄足以覆盖自己一生的开销，他便夺回了自身未来劳动时间的自主权；当财富可以支撑数倍于一生的消耗，他就获得了支配他人时间的权力。

### 从规则失信到日常犬儒

从社会学与政治学视角看，台面之上的明规则、主流叙事构成面向大众的显学，承担塑造公平预期、维系秩序合法性的功能；而场域内部长期沉淀、未被成文的非正式惯例，便是人们口中的隐学。它对应布迪厄所说的社会资本，稀缺资源常常在这套隐性默契里优先分配。所谓开窍，即是看穿表层意识形态叙事，识别一个场域真实的分配逻辑。但这套认知本身不构成筹码：隐性圈层规则自带排他性，若无对等资源参与交换，仅仅看懂，依然难以跨越阶层壁垒。

> 民，辱则贵爵，弱则尊官，贫则重赏，以刑治民，则乐用；以赏战民，则轻死。故战事兵用曰强。民有私荣，则贱列卑官，富则轻赏。治民羞辱以刑，战则战。民畏死，事乱而战，故兵农息而国弱。
>
> （春秋） 商鞅 撰《商子》商子卷第五 《弱民第二十》，四部丛刊景上海涵芬馆藏明天一阁刊本，第4页

统治者希望把社会中的劳力、财富、信息和组织能力，尽可能导入国家设定的目标；同时限制独立于国家的资源与声望来源，以免形成难以控制的力量。古代秦国用耕作、军功、爵禄和刑罚来实现这点；后世网络由此衍生出 “愚民、弱民、疲民、辱民、贫民” 这一概括性说法。

强动员能够迅速集中资源，却难以替代可靠的信息反馈、社会信任与制度化纠错。当控制压过反馈、上级指标取代实际成效时，治理机器短期内或许显得更有力量，长期却可能积累信息失真、运行低效与信任损耗。

在现实生活中，如果规则执行难以预测、维权成本高昂，且权力与资源分布不对称，人们便会逐渐形成防范风险的习惯：先找关系、留后手，再决定是否信任他人。这些做法各有具体情境，却也可能在反复实践中沉淀为普遍的生存经验。

当正式规则无法稳定地被信赖为共同保障，关系网络与潜规则便容易成为个人避险的工具。犬儒也由此从一种情绪转化为日常的实践理性，并被网络包装成可消费的“开窍知识”。制度性不信任随之进入日常生活：公开规则依然存在，许多人却不敢确信它能平等、稳定地保护自己。于是，关系被视为非正式保险，忠诚被理解为利益绑定，善意需要经过风险评估，守规矩也伴随着对“是否只有自己吃亏”的盘算。潜规则因此不再局限于正式规则之外的例外，它还会反过来影响人们如何理解规则、判断他人并作出选择。
