### 推荐收藏顺序

如果优先考虑**有官方中文内容且公开易读**，建议先收藏：**贝莱德中国、品浩台湾繁中Insights、汇丰中国财富远见、高盛大中华区Insights、摩根大通中文地区页面和瑞银中国地区页面**。

如果优先考虑**完整的全球卖方研究体系**，应重点关注：**摩根大通、高盛、摩根士丹利、美国银行、花旗、瑞银、巴克莱、汇丰、德意志银行、法国巴黎银行和野村**的英文机构门户。其中大多数需要机构客户关系、邮箱验证、研究订阅或专业客户权限。

官方中文内容与英文完整研究库通常存在差异。中文地区站点更常见的内容包括财富管理、区域市场、基金资料、投资教育和精选市场观点。股票评级、行业模型、信用策略、利率曲线、外汇策略和跨资产交易框架，通常以英文研究门户最完整。

本清单明确排除中国本土金融机构。表内机构总部或集团身份分别位于美国、英国、瑞士、德国、法国、日本等非中国国家和地区；这不代表它们没有中国业务或中文地区网站。

所有研究材料都只是信息和研究输入，不构成针对任何个人的投资、税务、法律或会计建议。使用时应核对发布日期、适用地区、客户权限、研究免责声明、历史数据口径和潜在利益冲突。

*最后核验：2026年9月。研究门户、权限和地区页面可能随时间调整；如果链接跳转，请从相应机构官网首页或Research栏目重新进入。*
